================================================================================
KEY DIFFERENCES FROM HOURLY VERSIONS
================================================================================

CONUS404 LOADING:
  Daily:   Loads from pre-computed daily zarr file
           Path: conus404_skagit_precip_daily_full.zarr
           Variable: precip_daily
  
  Hourly:  Loads hourly netCDF files and sums them
           Path: hourly_ar_non_ar_events/ directory
           Variable: PREC_ACC_NC

UCLA LOADING:
  Daily:   Loads daily netCDF files (one file per day)
           Path: UCLA/daily_ar_non_ar_events/
           Variables: RAINC + RAINNC (summed directly, no increments)
  
  Hourly:  Loads hourly netCDF files, calculates increments, then sums
           Path: hourly_ar_non_ar_events/
           Variables: RAINC + RAINNC.diff() then .sum()

OTHER PRODUCTS:
  All other products (PRISM, Daymet, PNNL, GridMET) are loaded identically
  in both daily and hourly versions.

================================================================================
USAGE
================================================================================

These scripts can be run independently to generate plots using the daily
data approach for comparison with the hourly versions.

Example:
  python3 plot_ar_events_cumulative_spatial_bias_grid_3_days_daily.py

Output:
  PNG files saved to: spatial_plots/plots/
